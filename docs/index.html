Local lab/research prototype

J Thrust

Making Cancer research flow smoothly, so your life can too. Built for Researchers, made for the world.

Download J Thrust ZIP Run Instructions
J Thrust is not a clinical tool. It does not classify variants, diagnose disease, determine benign/pathogenic status, or make medical recommendations.

What it does

  • Uploads curated CSV datasets of public VUS examples.
  • Ranks variants using transparent rules.
  • Routes variants to missing-evidence paths.
  • Assigns next lab/research actors.
  • Shows evidence snapshots and simple evidence maps.
  • Adds constrained AI-assisted explanations.

What it does not do

  • Does not reclassify variants.
  • Does not use real patient data.
  • Does not replace variant curators or lab experts.
  • Does not make medical recommendations.

Mac setup

1. Extract the ZIP

Download the ZIP and extract it. Then open Terminal:

cd ~/Downloads/j-thrust

2. Start the backend

cd backend
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

Backend health check:

http://127.0.0.1:8000/api/health

3. Start the frontend

Open a second Terminal window:

cd ~/Downloads/j-thrust/frontend
npm install
npm run dev

Open:

http://localhost:5173

Windows setup

1. Extract the ZIP

Extract the ZIP. Then open PowerShell in the extracted j-thrust folder.

2. Start the backend

cd backend
py -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

If PowerShell blocks activation, run:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

3. Start the frontend

Open a second PowerShell window:

cd frontend
npm install
npm run dev

Open:

http://localhost:5173

Using the app

  1. Start backend and frontend.
  2. Open http://localhost:5173.
  3. Upload one of the CSV files from the data folder.
  4. Click View on a variant.
  5. Inspect the evidence map and AI-assisted explanation.

Included datasets:

  • demo_variants.csv
  • dataset_splicing.csv
  • dataset_population_gap.csv
  • dataset_mixed_validation.csv

Optional OpenAI setup

The app runs without an OpenAI key. Without a key, the AI explanation button falls back to a safe local template.

Bash (Mac)

export OPENAI_API_KEY="your_api_key_here"
export OPENAI_MODEL="gpt-4.1-mini"
uvicorn main:app --reload --port 8000

PowerShell (Windows)

$env:OPENAI_API_KEY="your_api_key_here"
$env:OPENAI_MODEL="gpt-4.1-mini"
uvicorn main:app --reload --port 8000
Never commit your API key into GitHub. Set it only as an environment variable.
